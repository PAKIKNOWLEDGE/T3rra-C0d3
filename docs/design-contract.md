无头禁令、文案语域）**不变，继续有效**。

## 一、锁定项（不许重开辩论）

| 项 | 值 | 依据 |
| --- | --- | --- |
| 风格族 | **`ark`**（工业信息系统） | 盲审结论：排版骨架本来就是 ark 的 |
| 应用深度 | **`complex`**（多区壳层 + 分层舞台 + 完整组件 + 协调动效） | 控制台类产品 |
| 明暗 | **只有暗色。亮色主题死了，不许复活** | 仓库主人明令 |
| 参考系 | `.grok/skills/ark-ui`——**只作视觉参考**。不加载其工作流、不跑其无头验证脚本 | 仓库主人明令（无头验证浪费 token，且 t3rra-core 本就禁用无头） |
| 范本 | `demo/ark-console.html`（静态单文件，已验收为"范本"级） | 见 §七已知缺陷 |

## 二、色板（语义角色，不是装饰）

```
--bg      #080a0b   近黑，唯一底色
--ink     #f4f6f6   正文白
--signal  #18d1ff   青。活动 / 停滞警示 / 主操作按钮，唯一主信号色
--state   #c8eb21   酸绿。只给"完成 / 在线 / 校验通过"态，不给任何装饰
--muted   #8d9396   次要文字
--rule    rgba(244,246,246,.14)   1px 弱线
--rule-strong rgba(244,246,246,.32) 1px 强线
--panel   rgba(8,10,11,.82)       面板底（ark token 原值；先前写的 rgba(10,13,14,.86) 无出处，已改）
--rule-control rgba(244,246,246,.40)  可点控件的边界，实测 4.20:1（原样用 --rule-strong 只有 2.62:1，低于 3:1）
```

**角色纪律**：

- 中性面 ≥75% 的构图；青色是**唯一**走强调的色，酸绿只做状态。
- **没有黄。** 黄是 endfield 的，已随亮色一起退场。
- 青色不做长正文；文字对比度按 WCAG 实测，不靠感觉。
- 焦点可见：2px 青色 outline + offset，不许只靠变色。

## 三、字体（三轨制）

| 轨 | 现行栈（范本用） | 说明 |
| --- | --- | --- |
| **展示轨** | `"Bahnschrift SemiCondensed/Condensed" → "Arial Narrow" → "Roboto Condensed" → "DIN Condensed"` | 全大写、`line-height .82–.95`、负字距。**待办**：Latin 展示字要一对可再分发的窄/宽体（宽体候选必须补上——参考图的展示字是**宽重**的，原候选表只有窄体） |
| **技术轨** | `"Space Grotesk", "IBM Plex Sans", system-ui` | 微标签：10–11px、`letter-spacing .08–.18em`、全大写 |
| **数据轨** | `"IBM Plex Mono", Consolas` | 一切数字/路径/代码，**必须 `font-variant-numeric: tabular-nums`** |
| CJK 正文 | `"HarmonyOS Sans SC"`（随包，仓库主人 2026-09-21 裁定），回退 Noto Sans SC → 微软雅黑 | 常规字距、舒适行高，不参与展示轨的怪胎排版；**展示轨里的 CJK 字形也落到它** |

规则：大与极小共存，**中间尺寸的填充物要少**；双语微标签成对出现
（CJK 主标签 + 短英文 micro-label），不许散落无角色的英文。

## 四、构图（舞台 + 仪表）

```
┌────────────── topbar：黑边壳，品牌 / 任务 / 链路态 / 语域 ──────────────┐
│ rail │                    STAGE（唯一主角）                     │ dossier │
│ 72px │   当前操作 = 舞台：标题 + 超大锚点数字 + 输出馈送 + 信号时间线 │ 336px   │
│      │                    角括号只给舞台                        │ 三个问题 │
├──────┴──────────────────────────────────────────────────────────┴─────────┤
│ baseline：步骤带（活动格 45° 切角）+ 指令坞 + 动作组                          │
└─────────────────────────────────────────────────────────────────────────────┘
```

**内容所有权**（防漂移的核心，抄自 ark 族配方）：

- **舞台拥有"正在发生的事"，但主标题是任务主题**：舞台大标题取自**指令**（如"主题令牌抽取" /
  双语第二行 "CSS Token Extraction"），当前工具与输出流住在这个舞台的**馈送**里。真产品与 ark 参考图
  都是这个分工（仓库主人 2026-09-21 裁定）。
  **缺席也是内容**——卡死时，停滞秒数就是舞台的锚点，馈送停在最后几行上。
- **边缘轨拥有导航**，**档案栏只拥有"被选中对象的详情"**（DOING / STUCK / NEEDS YOU
  三问，一条强边 + 表头代码，**无四面框**）。
- **底部只拥有元数据基线**：步骤带每工具一格、指令坞、动作组。
- **每屏一个超大锚点**：相位编号或停滞秒数。描边空心字是**标题第二行**的家族签名
  （实心 + 描边成对出现，见三张参考图），**不是背景幽灵字**——后者会跟真锚点抢视觉。
- 同一个数**在大字号上不许出现两处以上**（步骤带的 47s 与舞台的 47 是同一事实的主读数 + 侧读数，
  允许）。**正文句子里引用产品原文不算重复**：真产品的档案栏本来就同时给 `QUIET 47s` 与
  `NOTHING FOR 47s`，判据必须能自报。

## 五、几何

- `border-radius: 0`，永远。
- **面板 = 一条强边 + 表头代码**，如 `[ 04 // DOING ]`；禁的是**四面圆角卡片 chrome**（admin dashboard
  的语法）。参考图的 `ZONE // C-07` 面板是**细边框 + 一条青色强边**——"一条强边"不等于"禁止任何框线"。
- **45° 切角（chamfer）只给"活动"的东西**：活动步骤格、可点的主操作。【未验：参考图里切角出现在
  大块斜切场，"可点按钮切角"没有参考图支撑——范本保留现状，但这不是一条有证据的规则。】
- **角括号只给舞台**，不给 dossier、不给顶栏。
- 斜杠（slash）作分隔符；1px 线建立坐标，但不许让每个模块都变成框卡。

## 六、动效

| 用途 | 时长 | 曲线 |
| --- | --- | --- |
| 直接交互（按钮/输入） | 180–350ms | `cubic-bezier(.22,.8,.2,1)` |
| 区块进场（masked lateral reveal） | 500–900ms，可错峰 | 同上 |
| 注意力循环（未解决态呼吸块） | 1.6–2.4s | ease-in-out |

- 动效只用于**揭示层级或确认状态**；健康读数不动（动是注意力，注意力是预算）。
- 唯一常驻环境动效：未解决状态的呼吸块 + 活动格下划线脉冲。
- `prefers-reduced-motion: reduce` → 全部停，一行 CSS 解决，不许只停一半。
- 不做：扫描线、glitch、霓虹渐变、随机 HUD 噪声、假遥测。

## 七、范本的已知缺陷（修这些，别修别的）

`demo/ark-console.html` 被验收为**范本级**。2026-09-21 做过一轮三方盲审（我 + 视觉审 + 可用性审，
见 [`design-review.md`](./design-review.md)），当时这一节的三条处置如下：

| 原条目 | 状态 |
| --- | --- |
| 1. 错位（步骤带格内基线、dossier 窄窗挤压） | **已修**：编号与名字共用一条基线；档案栏键名不换行、值可断行；时间线上方 `LAST · tool.started` 被进场动画的永久 `clip-path` 切掉半行（旧范本就有），已修 |
| 2. 字体不全，**换展示字体是第一优先级** | **半修**：展示轨换成 Bahnschrift（DIN 系，Windows 自带，本机已确认），大标题补上家族签名（第二行描边）。**可再分发字体仍未选**，技术轨/数据轨仍回退系统字体 |
| 3. 范本是静态的，不是产品 | **部分修**：动作语义、HALT/Esc 中断与重新武装已可试；**视图切换、真实事件流、空闲/断链/等待裁决等边界态仍未覆盖** |

同轮还修了：停滞判决词（`SLOW/Not Required` → 产品的 `stalled` / `Nothing for 47s`）、
动作与模式混成一排、焦点环在填充按钮上不可见、停滞秒数出现四处、字号与字距档位过多、
窄窗口顶栏溢出与指令坞滚出屏幕、`--panel` 与 token 不一致。

**仍未修、且需要重开辩论的一条**：舞台主标题的归属——范本把"当前工具"当主标题，
真产品与参考图的舞台主标题是**任务主题**。详见 `design-review.md` §六.2。

## 八、验收方式（不可协商）

- **无头浏览器禁用**（沿用 t3rra-core 规矩）。不跑 ark-ui 的 audit/capture 脚本。
- 交付物给**可直接双击打开的路径** + 人话说明"看什么"，由**仓库主人的眼睛**验收。
  当前有一对可对比的文件：`demo/ark-console.html`（盲审后改过的）与
  `demo/ark-console-accepted-2026-09-21.html`（上次验收的原样备份）。
- 能自证的只有：文件自包含（无外部 fetch）、`file://` 可开、reduced-motion 覆盖存在。
  渲染、布局、动效、对比度——**只有人眼能判**。
  （2026-09-21 起还多两条机器可验的：无重复 id / 无悬空类名，做法见 `design-review.md` §五。）

# 盲审记录：为什么 endfield 那版"怎么弄都不对味"

日期：2026-09-21。对象：`t3rra-core` 的 field console（`docs/screens/field-console/`
下那套截图，即旧项目的现界面），对照参考系：`.grok/skills/ark-ui`（只作视觉参考，
不加载其验证流程）。

**结论一句话：token 层全对，构图层全错。** 黄是对的、方角是对的、双语微标签是对的、
工业文案是对的——但整屏没有"舞台"，全是仪表，密度均匀，没有锚点。
"不对味"不是颜色问题，是**构图语法**问题。

---

## 一、参考系在做什么（ark-ui 样例的标准答案）

从 `ark-ui` 宣传图样例（`assets/promo/output/01-cover-landscape.png`）读出的家族语法：

- **不对称 40/60 构图**：左侧文字场 + 右侧斜向错叠的窗口组，靠留白和 1px 线平衡
- **超大号数字锚点**：05 / 04 / 10 是视觉重心，不是元信息
- **描边空心大字**：标题第二行只描边不填充
- **45° 切角窗口**：chamfer 而不是圆角，也不是裸直角
- **十字线 / 校准标记 / 角括号**：只给需要"仪器感"的区域
- **"一个大 + 一堆极小"的编辑排版**：中间尺寸的填充物很少
- **每条线、每个代码、每个动画都有角色**：没有纯装饰

## 二、旧界面的六个病灶（按权重排序）

### 1. 没有舞台（最重）

Hypergryph 家族的核心语法是**"舞台 + 仪表"**（stage plus instrumentation）：
一个主导视觉场，其余贴边当仪器。旧界面的 PROCESS 视图是一列等宽小行——
**每一行都是仪器，没有东西在"演出"**。agent 正在跑的那个工具、那段思考，
应该是撑满舞台的主角；历史是侧轨，不是平铺日志。

### 2. 四边盒子 = 通用后台味

设计语言自己写着 technical panel = **一个强边 + 表头代码，避免四面卡片 chrome**。
旧界面里描述框、面板全是完整矩形边框——那是 admin dashboard 的语法。
鹰角的面板靠**一条 2px 强边 + 大面积平铺 + 留白**分区，不靠框线分区。

### 3. 没有大数字

参考系里 05/04/10 是锚点；旧界面里 **47 秒的停滞、STEP 03、TURN 01 全是 11px 元信息**。
"卡死 47 秒"这件事值得一个撑到面板 1/3 高的巨大 tabular 数字。
数字是这套语言里最强的乐器，旧界面只用了它的最小档。

### 4. 缺 45° 切角、角括号、斜杠

`border-radius: 0` 只是"不圆"，不是"有方向"。家族的指向性全靠
chamfer / bracket / slash：活动中的步骤格切一个 45° 角、舞台四角加角括号、
分隔用斜杠。只有直角，没有"切"。

### 5. 显示字体没有人格

鹰角的 Latin 展示字是 Bender / Novecento Sans Wide 那类**极宽或极窄**的怪胎，
`line-height .82–.95`、负字距。旧界面用 HarmonyOS Sans 全家桶——正常字宽的常规黑体，
怎么排都不对味，因为"宽/窄到反常"本身就是那个味的一半。
CJK 正文用它没问题，**Latin 展示字和数字必须换**。

### 6. 明暗主题身份选反了

Endfield 官方身份是**米白纸面 + 炭黑 + 信号黄**——亮场系统，暗色是例外。
旧界面在暗底上放黄，实际是 `ark` 族（近黑 + 冷信号色）的构图习惯，只是把青换成了黄。
**"怎么弄都不对味"的根本原因之一：用 ark 的骨架追 endfield 的皮。**

## 三、判决与转向

- **亮色主题：直接丢弃。**（仓库主人原话："我不想大晚上被闪瞎。"）
- **风格族：endfield → ark。** 排版骨架本来就是 ark 的，换过去是顺势不是重造。
- **验收产物**：`demo/ark-console.html`（单文件静态范本，仓库主人已验收：
  "错位、字体不全，但当个范本还可以"）。已知缺陷与待办见
  [`design-contract.md`](./design-contract.md) §七。

## 四、这份记录的用途

六个病灶 = 六条**不许回潮**的禁令。任何后续界面改动，先对照
[`design-contract.md`](./design-contract.md)（标准答案），再对照本文件（反面清单）。

## 二、色板（语义角色）

```
--bg      #080a0b   近黑，唯一底色
--ink     #f4f6f6   正文白
--signal  #18d1ff   青。活动 / 停滞警示 / 主操作，唯一主信号色
--state   #c8eb21   酸绿。仅「完成 / 在线 / 校验通过」态，不作装饰
--muted   #8d9396   次要文字
--rule    rgba(244,246,246,.14)   1px 弱线
--rule-strong rgba(244,246,246,.32) 1px 强线
--panel   rgba(8,10,11,.82)       面板底（ark token 原值）
--rule-control rgba(244,246,246,.40)  可点控件边界，实测 4.20:1（rule-strong 仅 2.62:1，低于 3:1）
```

**角色纪律**：

- 中性面 ≥75% 构图；青色为唯一强调色；酸绿仅状态。
- **无黄。** 黄属 endfield，已随亮色移除。
- 青色不作长正文；文字对比度按 WCAG 实算。
- 焦点可见：2px 青 outline + offset，不可只靠变色。

## 三、字体（三轨）

| 轨 | 现行栈（范本） | 说明 |
| --- | --- | --- |
| **展示** | `"Bahnschrift SemiCondensed/Condensed" → "Arial Narrow" → "Roboto Condensed" → "DIN Condensed"` | 全大写、`line-height .82–.95`、负字距。**待办**：可再分发的窄/宽成对 Latin 展示字（宽体候选须补——参考图为宽重） |
| **技术** | `"Space Grotesk", "IBM Plex Sans", system-ui` | 微标签：10–11px、`letter-spacing .08–.18em`、全大写 |
| **数据** | `"IBM Plex Mono", Consolas` | 数字/路径/代码，**必须** `font-variant-numeric: tabular-nums` |
| CJK 正文 | `"HarmonyOS Sans SC"`（随包，主人 2026-09-21 裁定）→ Noto Sans SC → 微软雅黑 | 常规字距；展示轨中的 CJK 字形也落到它 |

规则：大与极小共存，**中间尺寸填充少**；双语微标签成对（CJK 主标签 + 短英文 micro-label），不散落无角色英文。

## 四、构图（舞台 + 仪表）

```
┌────────────── topbar：品牌 / 任务 / 链路态 / 语域 ──────────────┐
│ rail │                    STAGE（唯一主角）              │ dossier │
│ 72px │  标题 + 超大锚点 + 输出馈送 + 信号时间线          │ 336px   │
│      │  角括号只给舞台                                   │ 三问    │
├──────┴──────────────────────────────────────────────┴─────────┤
│ baseline：步骤带（活动格 45° 切角）+ 指令坞 + 动作组          │
└────────────────────────────────────────────────────────────────┘
```

**内容归属**（防漂移）：

- **舞台拥有「正在发生的事」，主标题是任务主题**：大标题取自指令（双语第二行）；当前工具在**馈送**中。缺席也是内容——停滞时秒数即锚点，馈送停在最后几行。
- **边缘轨拥有导航**；**档案栏只拥有被选中对象详情**（DOING / STUCK / NEEDS YOU，一条强边 + 表头代码，无四面圆角框）。
- **底部只拥有元数据基线**：步骤带每工具一格、指令坞、动作组。
- **每屏一个超大锚点**：相位编号或停滞秒数。描边空心字是**标题第二行**的家族签名（实心+描边成对），**不是背景幽灵字**。
- 同一数**大字号不超过两处**（步骤带侧读数与舞台主读数允许）；**正文引用产品原文不算重复**。

## 五、几何

- `border-radius: 0`，始终。
- **面板 = 一条强边 + 表头代码**，如 `[ 04 // DOING ]`；禁的是**四面圆角卡片 chrome**。「一条强边」≠禁止任何框线（参考图 `ZONE // C-07` 为细边框 + 一条青强边）。
- **45° 切角只给「活动」的东西**：活动步骤格、可点主操作。【未验：参考图中切角在大块斜切场，「按钮切角」无参考图支撑——范本保留现状，非有证据的规则。】
- **角括号只给舞台**，不给 dossier、顶栏。
- 斜杠作分隔；1px 线建立坐标，但不让每个模块都变成框卡。

## 六、动效

| 用途 | 时长 | 曲线 |
| --- | --- | --- |
| 直接交互 | 180–350ms | `cubic-bezier(.22,.8,.2,1)` |
| 区块进场 | 500–900ms，可错峰 | 同上 |
| 注意力循环（未解决态呼吸） | 1.6–2.4s | ease-in-out |

- 动效只用于**揭示层级或确认状态**；健康读数不动。
- 常驻环境动效：未解决态呼吸块 + 活动格下划线脉冲。
- `prefers-reduced-motion: reduce` → 全部停（一行 CSS，不停一半）。
- 不做：扫描线、glitch、霓虹渐变、随机 HUD 噪声、假遥测。

## 八、验收方式（不可协商）

- **无头浏览器禁用**。不跑 ark-ui audit/capture。
- 交付物给**可直接打开的路径** + 「看什么」，由**仓库主人**目视验收。  
  可对比：`demo/ark-console.html`（盲审后修改版）与 `demo/ark-console-accepted-2026-09-21.html`（上次验收备份）。
- 能自证的只有：自包含（无外部 fetch）、`file://` 可开、reduced-motion 存在、无重复 id、无悬空类名。  
  渲染、布局、动效、对比度——**只能目视**。

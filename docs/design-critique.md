# 反面记录：endfield 风格的六个问题

日期：2026-09-21。对象：`t3rra-core` 的 field console（`docs/screens/field-console/` 截图）。  
对照：`.grok/skills/ark-ui`（仅视觉参考，不加载其验证流程）。

**结论**：token 层正确，构图层错误。黄、方角、双语微标签、工业文案都对——但整屏没有「舞台」，全是仪表，密度均匀，没有锚点。问题不在颜色，在**构图语法**。

---

## 一、参考系（ark-ui 样例）

- **不对称 40/60 构图**：左文右窗组，靠留白与 1px 线平衡
- **超大数字锚点**：05 / 04 / 10 是视觉重心
- **描边空心大字**：标题第二行只描边不填充
- **45° 切角窗口**：chamfer，非圆角、非裸直角
- **十字线 / 校准标记 / 角括号**：只给需要仪器感的区域
- **「一个大 + 一堆极小」**：中间尺寸填充少
- 每条线、代码、动画都有角色

## 二、六个问题（按权重）

### 1. 没有舞台（最重）

家族语法是**舞台 + 仪表**：一个主导视觉场，其余贴边当仪器。旧 PROCESS 视图是等宽小行——每行都是仪器，没有东西在「演出」。正在跑的工具与思考应撑满舞台；历史是侧轨，不是平铺日志。

### 2. 四边盒子 = 通用后台味

设计语言写明 technical panel = **一条强边 + 表头代码**，避免四面卡片 chrome。旧界面描述框全是完整矩形边框——admin dashboard 语法。鹰角面板靠 2px 强边 + 大面积平铺 + 留白分区。

### 3. 没有大数字

参考系里 05/04/10 是锚点；旧界面里 47 秒停滞、STEP 03、TURN 01 全是 11px 元信息。「卡死 47 秒」值得一个撑到面板约 1/3 高的 tabular 数字。数字是这套语言最强的乐器，旧界面只用了最小档。

### 4. 缺 45° 切角、角括号、斜杠

`border-radius: 0` 只是「不圆」，不是「有方向」。指向性靠 chamfer / bracket / slash：活动步骤格切角、舞台四角角括号、分隔用斜杠。只有直角，没有「切」。

### 5. 展示字体没有人格

参考系 Latin 展示字是极宽或极窄的怪胎（Bender / Novecento Sans Wide 类），`line-height .82–.95`、负字距。旧界面用 HarmonyOS Sans 全家桶——正常字宽黑体怎么排都不对味，因为「宽/窄到反常」本身就是味的一半。CJK 正文可用它；**Latin 展示字和数字必须换**。

### 6. 明暗主题身份选反了

Endfield 官方身份是米白纸面 + 炭黑 + 信号黄——亮场系统，暗色是例外。旧界面在暗底上放黄，实际是 ark 构图习惯（近黑 + 冷信号色）只是把青换成了黄。**用 ark 骨架追 endfield 皮，是「不对味」的根本原因之一。**

## 三、判决与转向

- **亮色主题：移除。**（仓库主人：「我不想大晚上被闪瞎。」）
- **风格族：endfield → ark。** 排版骨架本为 ark，转向是顺势。
- **验收产物**：`demo/ark-console.html`（已验收为范本级）。已知缺陷见 [`design-contract.md`](./design-contract.md) §七。

## 四、用途

六个问题 = 六条**不许回潮**的禁令。后续界面改动先对照 [`design-contract.md`](./design-contract.md)（正面标准），再对照本文件（反面清单）。
